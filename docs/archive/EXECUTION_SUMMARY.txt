  KEY METRICS IMPLEMENTED                                                  


RETRIEVAL METRICS (how well we find relevant documents)
 Precision@K (k=1,3,5,10)
   "Of top-K results, how many are relevant?"
 Recall@K (k=5,10,20)
   "Of all relevant docs, how many did we find?"
 Mean Reciprocal Rank (MRR)
   "At what position is the first relevant doc?"
 NDCG@K (k=5,10)
    "How good is the ranking quality?"

GENERATION METRICS (quality of AI-generated answers)
 Faithfulness
   "Is answer grounded in retrieved sources (no hallucination)?"
 Relevance
   "Does answer address the question?"
 Completeness
   "Is information sufficient?"
 Source Accuracy
    "Are cited sources correct?"

PERFORMANCE METRICS (system speed & resources)
 Latency (avg, p95, p99)
   "How fast are query responses?"
 Throughput
   "How many queries per second?"
 Memory Usage
    "How much RAM is consumed?"
