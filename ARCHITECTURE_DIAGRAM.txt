              PHASE 2: METRICS FRAMEWORK SETUP ( COMPLETED)               

                                                                              
  evaluation/metrics/metrics_calculator.py                                   
                                                                              
            
   RETRIEVAL METRICS                                                      
            
   • PrecisionRecallCalculator                                            
      Precision@K, Recall@K                                             
   • MeanReciprocalRankCalculator                                         
      MRR (first relevant rank)                                         
   • NDCGCalculator                                                       
      Normalized Discounted Cumulative Gain                             
            
                                                                              
            
   GENERATION METRICS                                                     
            
   • Faithfulness     → Answer grounded in sources                        
   • Relevance        → Answer addresses question                         
   • Completeness     → Information coverage                              
   • Source Accuracy  → Cited sources valid                               
            
                                                                              
            
   PERFORMANCE METRICS                                                    
            
   • Latency          → Response time (avg, p95, p99)                     
   • Throughput       → Queries per second                                
   • Memory Usage     → RAM consumption                                   
            
                                                                              
  Targets Defined (evaluation_config.json)                                  
  • Precision@3: ≥70%   • Faithfulness: ≥95%   • Avg Latency: ≤3000ms      
  • Recall@5: ≥60%      • Relevance: ≥90%      • Throughput: ≥0.5 q/s      
  • MRR: ≥75%           • Completeness: ≥80%   • Memory: ≤2048MB           
  • NDCG@10: ≥70%       • Source Acc: ≥95%                                  
                                                                              

                                      


           PHASE 3: INFERENCE & METRICS CALCULATION (READY ⏳)             

                                                                              
  evaluation/run_evaluation.py (to be created)                              
                                                                              
  For each of 85 QA pairs:                                                  
                                                                            
   1⃣  Load question from dataset                                        
      "What is data structure?"                                          
                                                                            
   2⃣  Query RAG API                                                     
      POST http://localhost:8000/api/query                               
                                                                            
   3⃣  Retrieve relevant documents (top-5)                              
      docs = [doc1, doc2, doc3, doc4, doc5]                              
                                                                            
   4⃣  Generate answer using LLM                                         
      answer = "A data structure is an organized way to..."             
                                                                            
   5⃣  Calculate retrieval metrics                                       
      Precision@3 = relevance(top3) / 3                                  
      Recall@5 = found / total_relevant                                  
      MRR = 1 / position_first_relevant                                  
      NDCG@10 = DCG / ideal_DCG                                          
                                                                            
   6⃣  Evaluate generation quality                                       
      Faithfulness = grounded_in_sources(answer)                         
      Relevance = addresses_question(answer)                             
      Completeness = sufficient_info(answer)                             
      Source Accuracy = sources_valid(answer)                            
                                                                            
   7⃣  Measure performance                                               
      Latency = end_time - start_time                                    
      Throughput = 1000 / avg_latency                                    
      Memory = get_memory_usage()                                        
                                                                            
   8⃣  Save result                                                       
       results/qa_001_result.json                                         
                                                                              
  Aggregate metrics across all 85 queries                                   
  Output: Individual results + aggregated metrics                           
                                                                              

                                      


           PHASE 4: ANALYSIS & REPORTING (READY ⏳)                        

                                                                              
  evaluation/analyze_results.py (to be created)                             
                                                                              
   Load Phase 3 Results                                                  
     Load all individual results from evaluation/results/                
                                                                            
   Aggregate Metrics                                                      
     Average precision_at_3 = mean(all_p3)                               
     Average recall_at_5 = mean(all_r5)                                  
     Average latency = mean(all_latencies)                               
     ... (all metrics aggregated)                                        
                                                                            
   Compare Against Targets                                                
     If avg_precision < target_precision →   NEEDS WORK                
     If avg_recall ≥ target_recall →  GOOD                            
     Identify all gaps                                                   
                                                                            
   Generate Visualizations                                                
     Precision/Recall curve                                              
     Latency distribution histogram                                      
     Category performance heatmap                                        
     Error analysis by category                                          
     Metric radar chart                                                  
                                                                            
   Create Recommendations                                                 
     "Precision is low (65% vs 70% target)"                              
     "Try: Improve embedding model or adjust chunk size"                 
     "Latency is good (2.5s vs 3s target)"                               
     "Keep current retrieval parameters"                                 
                                                                            
   Generate Reports                                                       
      evaluation_report.html ( MAIN REPORT - open in browser)           
      evaluation_report.json (detailed data)                              
      recommendations.txt (optimization suggestions)                      
      visualizations/ (PNG charts)
